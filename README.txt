AHP-MCDA-Sim: Research Data Repository
========================================

This repository contains the input data, model configuration, and output
results for the national-scale AHP-MCDA basin screening analysis of 13
Canadian sedimentary basins for geological CO2 storage, as reported in
the accompanying manuscript.

Files
-----

AppendixA_pairwise_matrix.csv
    The 15x15 AHP pairwise comparison matrix (criterion judgements).

weights.csv
    Final AHP-derived criterion weights (15 criteria) and their
    percentage share of the total.

class_definitions.csv
    The class labels and raw scores assigned to each qualitative class
    of each of the 15 criteria.

assignments.csv
    The class assigned to each of the 13 basins for each of the 15
    criteria.

scores_tiers.csv
    Final composite suitability score, rank, and priority tier for
    each of the 13 basins.

mc_weights.csv
    Monte Carlo criterion weight statistics (mean, standard deviation,
    stability flag) across all simulated perturbations.

tier_stability.csv
    Per-basin tier stability: the percentage of Monte Carlo simulations
    in which each basin retained its deterministic tier.

full_results.json
    Complete run record (analysis mode, perturbation mechanism, sigma,
    iteration count, criteria, weights, assignments, scores, and tiers)
    sufficient to exactly reproduce this run.

Reproducing this analysis
--------------------------

All files in this repository can be regenerated by loading this dataset
into the AHP-MCDA-Sim application (Mode 4: AHP-MCDA + Monte Carlo) and
clicking "Run simulations." The application is openly available at:
https://doi.org/10.5281/zenodo.21927103
